## Data

- **No human labelled the test set.** Labels come from three LLM families (agy, Fable, Haiku) labelling independently against the seed, merged by `eval/gen/adjudicate.py` (2 of 3 wins; no majority = the safest state). Five real-model smoke checks passed locally and again over Render HTTPS, covering explicit confirmation/replay, ambiguity, insufficient funds, bill payment and session isolation. Initial provider timeouts and a smoke-script assertion error about seeded transaction history are preserved alongside corrected results; these are deployment checks, not accuracy estimates or held-out evaluation.

No ASR service was exposed. The README demo link and deployment evidence were published on GitHub. Physical-phone testing, native copy review and author presentation rehearsal remain human follow-ups; no held-out set was run. Evidence and limitations are in docs/30 and docs/31.
